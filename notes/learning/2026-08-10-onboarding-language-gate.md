## 2026-08-10 — Name the user's job before the system object

Context: The first clean-computer setup exposed copy such as “neutral profile,” “authored guidance,” raw save paths, and editing instructions that required more explanation than the task itself.

Learning: Setup copy must say what the person is doing, what the button does, and what changes before it names an internal object. More technical depth does not justify less plain language.

Risk: A working transfer package can still fail its first-use test if a new user cannot tell what they are choosing or what will happen next.

Follow-up: Compare the source-mapped script with the fresh voice-manifest script, then use the approved language to write failing UX tests before rebuilding the interface.
